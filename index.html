    How Tessera builds

    • One job per project

      Each project starts from a single problem. If a feature doesn't serve it, it doesn't ship.

    • Source in the open

      The code is public on GitHub wherever possible, so you can read what a project does before you run it.

    • Descriptions you can check

      Every description here comes from the project's own README and says what it does today.
